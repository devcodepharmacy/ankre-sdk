# Ankre SDKs

The iOS and Android SDKs for [Ankre](https://stats.getmangoapp.com) app analytics and revenue attribution. This repository holds only the SDKs; the service itself is separate.

- **iOS:** Swift package `AnkreKit` (iOS 17+). In Xcode, add `https://github.com/devcodepharmacy/ankre-sdk` and link `AnkreKit`. Setup: [ios/README.md](ios/README.md).
- **Android:** add `maven("https://jitpack.io")` and `implementation("com.github.devcodepharmacy:ankre-sdk:<commit>")`. Setup: [android/README.md](android/README.md).
